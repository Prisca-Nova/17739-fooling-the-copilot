## Reading

- The 30B is clearly better than the 7B on safe code (39% vs 14%), with the gain almost entirely on XSS.
- On command injection it still calls **every** safe stub vulnerable, often with **wrong reasoning**, not caution
  (Eileen's notes): it claims `execFile` runs through a shell (`cmdi_003_safe`, `cmdi_011_safe`), or that an anchored
  regex `/^\d{1,4}x\d{1,4}$/` lets `128x128; rm -rf /` through (`cmdi_015_safe`).
- **Against the rule we set on 2026-10-21** (use the 30B in the main experiment only with specificity ≥ ~50% on this
  sample): **39% falls short.** See the decision log for what we do with that.
- Practical finding: **Kaggle's free GPUs run the 30B at ~3 s per call**, ~5× faster than the 7B on Prisca's laptop,
  and without the laptop's memory problems.
